# Demo video

Place the final short demo here as `endoguard-demo.mp4`.

Recommended recording flow:

1. Show the API status as connected.
2. Select or upload one endoscopy image.
3. Run **DPO only** and briefly show the response.
4. Run **DPO + verifier** and show verified or corrected entities.
5. Ask one follow-up question.
6. Show the report view and download option.

Keep the video around 60–120 seconds, use 1080p if practical, and do not show
tokens, Kaggle Secrets, notebook environment panels, patient identifiers, or a
private ngrok dashboard.
